# ซิงก์พนักงานเข้า Google Sheet ของ Department P&L

ทุกครั้งที่บันทึกพนักงานในระบบนี้ `scr/backend.gs` จะคัดลอกข้อมูลเข้าแท็บ **`Employees`** ของ Google Sheet
`Department P&L Database` (repo `department-pl-business-plan`) ด้วย ตั้งค่าที่ `PL_SYNC` ต้นไฟล์ `backend.gs`

| เหตุการณ์ | สิ่งที่เกิดในแท็บ `Employees` |
|---|---|
| เพิ่มพนักงาน | เพิ่มหนึ่งแถว |
| แก้ไขข้อมูล / ลาออก (`status`, `exitDate`) | แก้แถวเดิมของรหัสนั้น |
| เปลี่ยนรหัสพนักงาน | แถวเดิมเปลี่ยนรหัส ไม่เกิดแถวซ้ำ |
| ลบพนักงาน | คงแถวไว้ ตั้งสถานะ `Deleted` เพื่อเก็บประวัติจำนวนคน |
| Import ทั้งชุด (`saveData` พร้อม `orgData`) | อัปเดตทุกคน คนที่ไม่อยู่ในชุดใหม่ถูกตั้งเป็น `Deleted` |

คอลัมน์: รหัส, ชื่อ, แผนก, แผนกย่อย, กะ, ตำแหน่ง, ประเภท, บริษัท, สถานะ, วันที่เริ่มงาน, วันที่ออก, ซิงก์ล่าสุด
**ไม่ส่ง** เบอร์โทร รูปภาพ สีการ์ด และสายบังคับบัญชา

แท็บนี้ระบบเขียนเอง อย่าแก้หัวตารางหรือรหัสด้วยมือ ถ้าหัวตารางไม่ตรง ระบบจะไม่เขียนทับและบันทึกความผิดพลาดแทน

## ถ้าเขียนเข้าชีต P&L ไม่สำเร็จ
การบันทึกพนักงานในระบบนี้ยังสำเร็จตามปกติ ผลการซิงก์อยู่ในฟิลด์ `plSync` ของคำตอบ (`ok` / `off` / `failed: …`)
และความผิดพลาดถูกบันทึกในแท็บ `Logs` ของไฟล์นี้ (Action = `plSyncFailed`)

## ตั้งค่าครั้งแรก
1. บัญชี Google ที่เป็นเจ้าของ Apps Script ต้องมีสิทธิ์ **Editor** ในชีต P&L
2. deploy ตามปกติ (`docs/apps-script-deploy.md`) ครั้งแรกอาจต้องกดอนุญาตสิทธิ์ Google Sheets เพิ่มในหน้า Apps Script
3. เปิดโปรเจกต์ Apps Script เลือกฟังก์ชัน `backfillEmployeesToPlSheet` แล้วกด Run **หนึ่งครั้ง** เพื่อคัดลอกพนักงานที่มีอยู่แล้วทั้งหมด

ปิดการซิงก์: ตั้ง `PL_SYNC.SPREADSHEET_ID` เป็น `""`

## ทดสอบ
